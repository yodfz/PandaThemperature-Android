# 最高最低温度功能开发 - 开发计划

## 需求背景

单片机新增了GATT服务扩展功能，包括：
1. **最高最低温度特性** (UUID: 12340024-1234-5678-1234-56789ABCDEF0)
   - 可读：手机可以读取当前最高最低温度
   - 可通知：温度记录更新时自动通知手机
   - 数据格式：4字节（最高温度2字节 + 最低温度2字节，单位0.01°C）

2. **重置最高最低温度特性** (UUID: 12340025-1234-5678-1234-56789ABCDEF0)
   - 可写：手机写入任意值即可重置最高最低温度记录
   - 重置后自动保存到Flash并通知手机

UI需求：
- 在实时数据卡片中，在温湿度显示下方新增一行显示最高最低温度
- 在设置页面的设备状态卡片最下方增加"重置最高最低温湿度"按钮

## 实现方案

### 1. 蓝牙层扩展

#### 1.1 BleConstants.kt
- 添加两个新特性的UUID常量：
  - `MAX_MIN_TEMP_CHAR = "12340024-1234-5678-1234-56789ABCDEF0"`
  - `RESET_MAX_MIN_TEMP_CHAR = "12340025-1234-5678-1234-56789ABCDEF0"`

#### 1.2 BleManager.kt
- 在 `cacheServices()` 中缓存最高最低温度特性
- 在 `getCharacteristicByUuid()` 中支持新特性查找
- 在 `cleanup()` 中清理新特性引用

### 2. 数据模型和业务逻辑层

#### 2.1 MainViewModel.kt
- 添加状态管理：
  - `_maxTemperature: StateFlow<Float?>`
  - `_minTemperature: StateFlow<Float?>`
- 添加方法：
  - `readMaxMinTemperature()`: 读取最高最低温度
  - `resetMaxMinTemperature()`: 重置最高最低温度
- 在 `initializeDevice()` 中：
  - 将 `totalSteps` 从 6 改为 7
  - 添加第 5 步：读取最高最低温度
  - 在订阅实时数据时，同时订阅最高最低温度通知
- 在 `subscribeRealtimeData()` 中：
  - 订阅最高最低温度特性的通知
- 在 `resetConnectionState()` 中：
  - 清空最高最低温度状态

### 3. UI层

#### 3.1 RealtimeDataCard.kt
- 在温湿度显示下方新增一行
- 显示格式："最高：XX°C / 最低：XX°C"
- 样式与现有保持一致

#### 3.2 StatusCard.kt
- 在状态项列表最下方添加"重置最高最低温湿度"按钮
- 仅在设备连接时可用
- 点击后调用 ViewModel 的重置方法

#### 3.3 SettingsScreen.kt
- 将重置回调传递给 StatusCard

### 4. 数据格式处理

- 4字节数据解析：
  - 前2字节：最高温度（有符号 short，单位0.01°C）
  - 后2字节：最低温度（有符号 short，单位0.01°C）
- 使用 `ByteBuffer` 小端序读取，除以 100.0f 转换为摄氏度

## 注意事项

1. 重置操作写入任意值（如 `byteArrayOf(0x00)`）即可
2. 重置后设备会自动通知，无需手动读取
3. 保持与现有代码风格一致
4. 错误处理：读取失败时显示 "--"
5. 任务进度步骤从6步增加到7步，需要更新所有步骤的序号
