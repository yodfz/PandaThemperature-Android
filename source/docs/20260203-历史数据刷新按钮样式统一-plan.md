# 历史数据刷新按钮样式统一 - 开发计划

## 需求背景

- 历史数据页面底部的“强制刷新”按钮比筛选按钮更大，导致视觉不一致。
- 产品希望两个按钮尺寸保持一致，避免造成层级冲突和误导性的重点强调。

## 现状分析

- 筛选按钮使用 `FloatingActionButton`，`Modifier.size(48.dp)`，图标尺寸为 `24.dp`。
- 刷新按钮同样使用 `FloatingActionButton`，但尺寸为 `56.dp`，图标尺寸 `28.dp`。
- 两个按钮位于同一列垂直排列，目前刷新按钮的尺寸与筛选按钮不统一。

## 实现方案

1. 在 `HistoryScreen.kt` 中，将刷新按钮的 `Modifier.size` 调整为 `48.dp`。
2. 同时把刷新按钮的内部图标尺寸修改为 `24.dp`，保持与筛选按钮一致。
3. 保留刷新按钮的主色调和点击逻辑，避免影响交互行为。

## 开发计划

- [x] 1. 检查 `HistoryScreen.kt` 中 FAB 的当前尺寸配置。
- [x] 2. 调整刷新按钮尺寸与图标大小，使其与筛选按钮一致。
- [x] 3. 自检 UI 结构，确认布局未受影响。
