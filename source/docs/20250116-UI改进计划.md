# UI改进计划

## 需求背景

用户提出UI改进需求，要求：
1. 取消第一行的大标题
2. 第一行增加简略状态，未连接时可点击弹出蓝牙连接列表
3. 第一页显示实时温湿度 + 历史温湿度
4. 日志不需要显示
5. 设置单独再开一个TAB
6. 考虑全面屏的上下占位问题
7. 重新设计颜色体系，不要紫色，符合温度计的色彩

## 实现方案

### 1. 色彩体系重新设计

**温度计主题色彩**：
- **温度颜色**：橙红色系（Deep Orange-700 `#FF5722`）- 代表热量
- **湿度颜色**：蓝色系（Blue-700 `#1976D2`）- 代表水
- **背景**：清爽的白色系（Grey-100 `#F5F5F5`）
- **主色调**：使用温度橙色作为Material Design主色

### 2. 状态栏改造

- 移除原有的详细状态显示（历史记录数、采集间隔等）
- 简化为：连接状态指示点 + 状态文本 + 设备名称
- 未连接时：显示"未连接"，设备名称显示"点击连接设备"（可点击）
- 已连接时：显示"已连接"，显示实际设备名称（点击可断开）
- 合并到第一行（原header位置）

### 3. TAB切换实现

- 使用Material3的TabRow实现TAB导航
- 两个TAB：**首页**、**设置**
- 首页内容：实时温湿度卡片 + 历史温湿度卡片
- 设置页内容：设备配置卡片 + 设备状态卡片

### 4. 主界面重构

- **删除**：大标题（header中的h1和p）
- **删除**：连接控制卡片（功能已合并到状态栏）
- **删除**：日志卡片
- **保留**：实时数据卡片、历史数据卡片（合并到首页）
- **移动**：设备配置卡片、设备状态卡片（移动到设置页）

### 5. 全面屏安全区域处理

- 使用`WindowInsets.systemBars`获取系统栏高度
- 在Scaffold的topBar中手动添加topPadding
- 在content中手动添加bottomPadding
- 确保内容不会被系统栏遮挡
