# 界面主题和电池优化功能开发计划

> 开发日期：2026-01-26

## 一、需求背景

用户提出三个界面优化需求：

1. **固定主题色**：界面不随着手机系统改变主题色，始终保持深色主题
2. **电池能量条优化**：电池能量条应该根据电量百分比显示不同高度，颜色从绿色（高电量）-> 黄色（中电量）-> 红色（低电量）逐步变化，电量0时不显示
3. **未连接时的玻璃模糊效果**：未连接时，按钮背后的界面呈现玻璃模糊（毛玻璃）效果

## 二、实现方案

### 2.1 固定主题色

**文件：** `app/src/main/java/com/example/pandatemperature/ui/theme/Theme.kt`

**修改内容：**
- 将 `PandaTemperatureTheme` 函数的 `darkTheme` 参数默认值从 `isSystemInDarkTheme()` 改为固定 `true`
- 将 `dynamicColor` 参数默认值从 `true` 改为 `false`
- 移除动态颜色逻辑，始终使用 `DarkColorScheme`

**代码变更：**
```kotlin
@Composable
fun PandaTemperatureTheme(
    darkTheme: Boolean = true,  // 固定为深色主题
    dynamicColor: Boolean = false,  // 禁用动态颜色
    content: @Composable () -> Unit
) {
    val colorScheme = DarkColorScheme  // 直接使用深色配色方案
    // ...
}
```

### 2.2 电池能量条优化

**文件：** `app/src/main/java/com/example/pandatemperature/ui/components/BatteryIndicator.kt`

**当前逻辑：**
- 能量条高度已根据电量百分比正确计算
- 颜色阈值：>50%绿色，>20%黄色，否则红色
- 电量<=0时不显示

**优化方案：**
- 调整颜色阈值，使其更合理：
  - >60%：绿色（高电量）
  - 20%-60%：黄色（中电量）
  - <20%：红色（低电量）
  - <=0%：不显示能量条
- 确保能量条高度正确显示（从底部向上填充）
- 保持能量条颜色平滑过渡

### 2.3 未连接时的玻璃模糊效果

**文件：** `app/src/main/java/com/example/pandatemperature/ui/components/RealtimeDataCard.kt`

**实现方案：**
- 方案A（推荐）：使用半透明背景 + 毛玻璃效果模拟
  - 在未连接时，为卡片背景添加半透明白色/灰色遮罩层
  - 使用 `Modifier.background()` 添加半透明背景
  - 配合 `MaterialTheme.colorScheme.surface.copy(alpha = 0.7f)` 实现毛玻璃效果
  
- 方案B：使用 `RenderEffect.createBlurEffect()`（需要 Android 12+）
  - 使用 `Modifier.graphicsLayer { renderEffect = RenderEffect.createBlurEffect(...) }`
  - 仅支持 Android 12+ (API 31+)

**推荐使用方案A**，因为：
1. 兼容性更好（支持所有 Android 版本）
2. 性能更好（不需要实时模糊计算）
3. 视觉效果接近毛玻璃效果

**具体实现：**
- 在 `RealtimeDataCard` 的 `Surface` 中，当 `!isConnected` 时：
  - 在卡片背景上叠加半透明遮罩层
  - 使用 `Box` 叠加层实现模糊效果
  - 连接按钮保持清晰可见（在遮罩层之上）

## 四、技术要点

### 4.1 主题固定
- 移除 `isSystemInDarkTheme()` 依赖
- 移除 `dynamicColor` 和 `Build.VERSION.SDK_INT >= Build.VERSION_CODES.S` 判断
- 直接使用 `DarkColorScheme`

### 4.2 电池能量条
- 能量条高度：`fillWidth = (width - terminalWidth - strokeWidth * 2) * fillPercent`
- 颜色阈值：
  - `percent > 60` -> 绿色 `Color(0xFF4CAF50)`
  - `percent > 20` -> 黄色 `Color(0xFFFFC107)`
  - `percent > 0` -> 红色 `Color(0xFFF44336)`
  - `percent <= 0` -> 不显示

### 4.3 玻璃模糊效果
- 使用半透明背景层：`Color.White.copy(alpha = 0.3f)` 或 `MaterialTheme.colorScheme.surface.copy(alpha = 0.7f)`
- 使用 `Box` 叠加层实现
- 确保连接按钮在遮罩层之上，保持可点击

## 五、注意事项

- 主题固定后，应用将始终显示深色主题，不受系统设置影响
- 电池能量条颜色阈值可根据实际使用体验调整
- 玻璃模糊效果使用半透明遮罩模拟，如需真实模糊效果可考虑使用第三方库
- 确保未连接时的连接按钮仍然清晰可见且可点击
