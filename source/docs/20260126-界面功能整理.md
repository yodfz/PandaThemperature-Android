# 界面功能整理文档

> 用于界面重新设计的参考文档  
> 整理日期：2026-01-26

## 一、整体架构

### 1.1 导航结构
- **底部导航栏**（NavigationBar）：3个Tab页面
  - 首页（Home）
  - 历史数据（History）
  - 设置（Settings）

### 1.2 页面结构
```
MainScreen (主容器)
├── HomeScreen (首页)
├── HistoryScreen (历史数据页)
└── SettingsScreen (设置页)
```

---

## 二、首页（HomeScreen）

### 2.1 布局结构
- **顶部状态栏**：StatusBar 组件
- **实时数据卡片**：RealtimeDataCard 组件
- **历史数据预览卡片**：HistoryCard 组件（显示最近20条记录）

### 2.2 StatusBar（设备状态栏）
**位置**：首页顶部

**功能**：
- 显示连接状态（已连接/未连接）
- 显示设备名称
- 显示任务状态（如"正在读取温度"等）
- 点击可连接/断开设备

**视觉设计**：
- 连接状态：绿色圆点 + "已连接" + 设备名称
- 未连接状态：红色圆点 + "未连接" + "点击连接设备"
- 渐变背景（连接时绿色渐变，未连接时灰色渐变）
- 边框设计（连接时绿色边框，未连接时红色边框）

**交互**：
- 未连接时点击：弹出设备选择对话框
- 已连接时点击：断开连接（需确认）

### 2.3 RealtimeDataCard（实时数据卡片）
**位置**：StatusBar 下方

**功能**：
- 显示实时温度（大号数字，红色）
- 显示实时湿度（大号数字，青色）
- 显示最高/最低温度
- 显示电池电量（v1.1新增）
- 显示最后更新时间
- 点击温度/湿度区域可手动读取数据

**数据展示**：
- **温度**：大号数字 + "°C" + "温度"标签，红色主题
- **湿度**：大号数字 + "%" + "湿度"标签，青色主题
- **最高/最低温度**：横条显示，格式"最高：XX.X°C / 最低：XX.X°C"
- **电池信息**：电池图标（带百分比）+ 电压值（v1.1新增）
- **更新时间**：右上角显示，格式"HH:mm:ss"

**视觉设计**：
- 温度区域：红色边框 + 红色渐变背景，可点击
- 湿度区域：青色边框 + 青色渐变背景，可点击
- 最高最低温度：灰色渐变背景横条
- 加载状态：显示"LOADING"文字

**交互**：
- 点击温度区域：手动读取温度（需已连接）
- 点击湿度区域：手动读取湿度（需已连接）

### 2.4 HistoryCard（历史数据预览卡片）
**位置**：RealtimeDataCard 下方

**功能**：
- 显示最近20条历史记录（表格形式）
- 表格列：时间 | 温湿度（上下排列）

**数据展示**：
- **表头**：灰色背景，显示"时间"和"温湿度"
- **数据行**：斑马纹效果（单双行不同背景色）
  - 时间：左对齐，格式"yyyy-MM-dd HH:mm:ss"
  - 温度：右对齐，红色，格式"XX.X°C"
  - 湿度：右对齐，青色，格式"XX.X%"

**视觉设计**：
- 边框设计（浅灰色）
- 表头：灰色背景
- 数据行：斑马纹（单行白色，双行浅灰色）

**交互**：
- 无交互（首页预览模式）
- 如需查看全部数据，切换到"历史数据"Tab

## 三、历史数据页（HistoryScreen）

### 3.1 布局结构
- **顶部导航栏**：自定义 TopAppBar
  - 标题："历史数据" 或 "最近24小时温湿度曲线"
  - 返回按钮（图表视图时显示）
  - 菜单按钮（列表视图时显示）
- **内容区域**：
  - 列表视图：LazyColumn + SwipeRefresh
  - 图表视图：LineChart 组件

### 3.2 列表视图
**功能**：
- 显示所有历史数据记录（分页加载）
- 下拉刷新（需已连接设备）
- 滚动到底部自动加载更多
- 显示加载状态和"已加载全部数据"提示

**数据展示**：
- 使用 HistoryItem 组件（与首页 HistoryCard 中的表格行样式相同）
- 斑马纹效果
- 时间格式："yyyy-MM-dd HH:mm:ss"
- 温湿度格式：温度（红色）+ 湿度（青色）

**交互**：
- **下拉刷新**：从设备获取最新历史数据（需已连接）
- **滚动加载**：自动加载更多历史数据
- **菜单按钮**：
  - "查看最近24小时曲线图"：切换到图表视图
  - "清空列表"：清空所有历史数据（红色文字，需确认）

### 3.3 图表视图
**功能**：
- 显示最近24小时的温湿度曲线图
- 双Y轴设计（左侧温度，右侧湿度）
- 面积图 + 折线图组合
- 支持触摸交互（拖拽查看数据点）

**数据展示**：
- **图例**：顶部显示"温度 (°C)"和"湿度 (%)"
- **信息栏**：显示选中数据点的时间、温度、湿度
- **图表**：
  - 左侧Y轴：温度刻度（0-5条网格线）
  - 右侧Y轴：湿度刻度（0-5条网格线）
  - X轴：时间标签（最多6个）
  - 温度曲线：红色，带半透明面积填充
  - 湿度曲线：青色，带半透明面积填充
  - 选中竖线：拖拽时显示，松手后保留

**视觉设计**：
- 温度颜色：红色系（#FF6B6B）
- 湿度颜色：青色系（#4ECDC4）
- 网格线：浅灰色，半透明
- 坐标轴：深色，2dp线宽
- 面积图：渐变填充（从深到浅）

**交互**：
- **拖拽**：在图表上拖拽，显示对应数据点的信息
- **返回按钮**：返回列表视图

## 四、设置页（SettingsScreen）

### 4.1 布局结构
- **下拉刷新**：SwipeRefresh 包裹整个页面
- **设备配置卡片**：ConfigCard 组件
- **设备状态卡片**：StatusCard 组件

### 4.2 ConfigCard（设备配置卡片）
**功能**：
- 显示当前采集间隔（只读）
- 编辑按钮：打开配置编辑弹窗

**数据展示**：
- **标题**："⚙️ 设备配置"
- **当前采集间隔**：大号数字 + "秒"，带边框和渐变背景
- **编辑按钮**：右侧，需已连接设备才能点击

**视觉设计**：
- 边框设计（浅灰色）
- 采集间隔显示区域：蓝色边框 + 蓝色渐变背景

**交互**：
- **编辑按钮**：打开 ConfigModal 弹窗
- **下拉刷新**：自动读取设备配置（需已连接）

### 4.3 ConfigModal（配置编辑弹窗）
**功能**：
- 编辑采集间隔（10-3600秒）
- 输入验证和错误提示

**数据展示**：
- **标题**："设备配置"
- **输入框**：数字键盘，显示当前值
- **错误提示**：输入无效时显示红色错误信息

**交互**：
- **保存按钮**：验证并保存配置（需已连接设备）
- **取消按钮**：关闭弹窗
- **输入验证**：
  - 必须为数字
  - 范围：10-3600秒
  - 超出范围显示错误提示

### 4.4 StatusCard（设备状态卡片）
**功能**：
- 显示设备状态信息（只读）
- 重置最高最低温度按钮

**数据展示**：
- **标题**："📈 设备状态"
- **状态项**（每项带边框和渐变背景）：
  - 采集间隔：XX秒
  - 存储记录数：XXXX
  - 设备连接：是/否
  - 时间同步：是/否
- **重置按钮**：底部，需已连接设备且支持最高最低温度功能

**视觉设计**：
- 边框设计（浅灰色）
- 每个状态项：浅灰色渐变背景 + 边框

**交互**：
- **重置按钮**：重置设备的最高最低温度记录（需已连接设备）
- **下拉刷新**：自动读取设备状态（需已连接）

## 五、通用组件

### 5.1 DeviceSelectionDialog（设备选择对话框）
**功能**：
- 扫描并显示可用的蓝牙设备
- 选择设备进行连接

**数据展示**：
- **标题**："选择设备"
- **设备列表**：
  - 设备名称（粗体）
  - 设备地址（小字，灰色）
- **扫描状态**：显示"正在扫描设备..."和加载动画

**交互**：
- **点击设备**：选择并连接该设备
- **取消按钮**：关闭对话框，停止扫描
- **自动停止**：10秒后自动停止扫描

### 5.2 BatteryIndicator（电池指示器）
**功能**：
- 显示电池电量百分比（电池图标内）
- 显示电池电压（电池图标右侧）

**数据展示**：
- **电池图标**：
  - 根据电量显示不同颜色（绿色>50%，黄色20-50%，红色<20%）
  - 电量百分比文字显示在电池内（白色，粗体）
- **电压值**：电池右侧，格式"XX.XXV"

**视觉设计**：
- 电池图标：自定义绘制，带边框和填充
- 电量颜色：根据百分比动态变化

### 5.3 LineChart（曲线图组件）
**功能**：
- 双Y轴面积图
- 显示温度和湿度两条曲线
- 支持触摸交互

**数据展示**：
- 图例、信息栏、坐标轴、网格线、曲线、面积填充
- （详细见"历史数据页-图表视图"部分）

## 六、数据流和状态管理

### 6.1 连接状态
- **Disconnected**：未连接
- **Connecting**：正在连接
- **Connected**：已连接
- **Disconnecting**：正在断开

### 6.2 任务状态（TaskStatus）
- 显示当前正在执行的任务，如：
  - "正在读取温度"
  - "正在读取湿度"
  - "正在同步历史数据"
  - 等

### 6.3 数据同步
- **自动同步**：
  - 连接设备后自动读取温湿度
  - 进入设置页自动读取配置和状态
  - 历史数据自动同步（连接时）
- **手动同步**：
  - 点击温度/湿度区域手动读取
  - 下拉刷新历史数据
  - 下拉刷新设置页数据

## 七、视觉设计规范

### 7.1 颜色主题
- **温度颜色**：红色系（TemperatureColor）
- **湿度颜色**：青色系（HumidityColor）
- **成功颜色**：绿色（SuccessColor）
- **错误颜色**：红色（ErrorColor）

### 7.2 卡片设计
- **无阴影设计**：使用边框 + 渐变背景
- **边框颜色**：浅灰色，半透明（alpha 0.2-0.3）
- **渐变背景**：根据状态使用不同颜色的渐变

### 7.3 间距规范
- **卡片间距**：12dp（首页）
- **卡片内边距**：12-20dp
- **组件间距**：8-16dp

### 7.4 字体规范
- **标题**：titleLarge/titleMedium，粗体
- **数据**：headlineMedium，粗体
- **标签**：bodySmall/bodyMedium
- **时间**：bodySmall

## 八、交互规范

### 8.1 连接流程
1. 点击 StatusBar（未连接状态）
2. 检查权限 → 请求权限（如需要）
3. 检查蓝牙 → 请求启用蓝牙（如需要）
4. 开始扫描设备
5. 显示设备选择对话框
6. 选择设备 → 连接
7. 连接成功后自动同步数据

### 8.2 断开流程
1. 点击 StatusBar（已连接状态）
2. 确认断开（如需要）
3. 断开连接
4. 清空相关状态

### 8.3 数据读取
- **自动读取**：连接后自动读取温湿度
- **手动读取**：点击温度/湿度区域
- **加载状态**：显示"LOADING"文字

### 8.4 历史数据
- **首页预览**：显示最近20条
- **历史数据页**：分页加载，支持下拉刷新
- **图表视图**：显示最近24小时数据

## 十一、数据模型

### 11.1 TemperatureRecord（温湿度记录）
- timestamp: Long（Unix时间戳，秒）
- temperature: Float（温度，°C）
- humidity: Float（湿度，%）

### 11.2 DeviceStatus（设备状态）
- interval: Int?（采集间隔，秒）
- recordCount: Int?（存储记录数）
- isConnected: Boolean?（设备连接状态）
- isTimeSynced: Boolean?（时间同步状态）

### 11.3 TaskStatus（任务状态）
- 用于显示当前正在执行的任务信息

## 十二、总结

### 12.1 核心功能
1. **蓝牙设备管理**：扫描、连接、断开
2. **实时数据监控**：温度、湿度、电池信息
3. **历史数据管理**：列表查看、图表展示、数据同步
4. **设备配置**：采集间隔设置
5. **设备状态**：状态监控、最高最低温度重置

### 12.2 设计特点
- 卡片式布局，现代化设计
- 无阴影，使用边框和渐变背景
- 颜色主题统一（温度红色，湿度青色）
- 响应式交互（下拉刷新、自动加载）

### 12.3 技术栈
- Jetpack Compose
- Material3 设计规范
- MVVM 架构
- Room 数据库
- BLE 蓝牙通信
