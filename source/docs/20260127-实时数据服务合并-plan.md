# 实时数据服务合并 - 开发计划

## 需求背景

根据最新的蓝牙协议v1.1文档，温湿度数据不再通过单独的ESS服务获取，而是合并到新的"实时数据服务"中：

- **新服务UUID**：`12340030-1234-5678-1234-56789ABCDEF0`
- **新特征UUID**：`12340031-1234-5678-1234-56789ABCDEF0`
- **数据格式**：6字节（小端序）
  - `temperature`: int16（0.01°C）
  - `humidity`: uint16（0.01%RH）
  - `pressure_dhpa`: uint16（0.1 hPa）

**优势**：客户端一次读取即可获取所有实时数据（温度+湿度+气压），比分别读取三个特征更高效。

## UI需求

1. **首页实时数据卡片**：
   - 删除湿度下面的"最高最低温湿度"显示
   - 添加气压显示（替换最高最低温湿度）

2. **历史数据卡片**：
   - 在日期下面新增一行，显示气压值（12px字体大小）

## 技术细节

### 1. 实时数据解析

**数据格式（6字节，小端序）**：
- Offset 0-1: `temperature` (int16, 0.01°C)
- Offset 2-3: `humidity` (uint16, 0.01%RH)
- Offset 4-5: `pressure_dhpa` (uint16, 0.1 hPa)

**单位转换**：
- `temperature = tempRaw / 100.0f` （0.01°C -> °C）
- `humidity = humRaw / 100.0f` （0.01%RH -> %RH）
- `pressure = pressureRaw / 10.0f` （0.1 hPa -> hPa）

### 2. 向后兼容

**历史数据卡片**：

- 气压行（新增，12px字体）

## 注意事项

1. **数据流变更**：
   - 从三个独立的特征（温度、湿度、气压）合并为一个特征

2. **性能优化**：
   - 一次读取/订阅比三次读取/订阅更高效
