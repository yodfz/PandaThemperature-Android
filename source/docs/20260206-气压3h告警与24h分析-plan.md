# 气压 3h 告警（1.5–2 hPa）与 24 小时分析 - 开发计划

## 1. 需求背景

- **3h 气压下降 1.5–2 hPa 的告警/提示**：用户希望「3 小时内下降超过 1.5–2 hPa，通常预示着雷雨或大风即将到来」有明确的告警或提示。当前实现中：
  - **WapsLogic**：仅当 3h 下降 **≥2 hPa** 才触发「天气恶化，阴雨/大风可能」；**1.5–2 hPa** 区间没有单独档位。
  - **WeatherInsightsEngine**：用 EHR（hPa/h）判断，3h 下降 1.5–2 hPa 对应约 -0.5~-0.67 hPa/h，会落在「气压趋势整体平稳」，没有雷雨/大风提示。
- **24 小时气压分析**：「气压趋势与降水倾向」卡片目前只展示 **3h/6h** 的 ΔP 和 EHR，**没有 24 小时维度的描述**。用户举例：24h 内气压从高到低再涨回去时，应在该卡片中体现 24h 分析（变幅、先跌后涨等）。

## 2. 现状简述

| 位置                                              | 现状                                                                                                          |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `WapsLogic.kt`                                    | `WORSENING_DELTA_THRESHOLD = -2f`，3h ΔP &lt; -2 才「天气恶化」；`STORM_DELTA_THRESHOLD = -4f` 才暴风雨预警。 |
| `WeatherInsightsEngine.buildPressureTrendInsight` | 仅用 last24h 做数据充分性；结论与 metrics 全是 Δ3h、Δ6h、EHR(3h)，无 24h 气压描述。                           |
| `WeatherInsightsEngine.buildOverviewSummary`      | 24h 总结里只有「近 3 小时气压…」一句，无 24h 气压变幅/趋势。                                                  |
| 通知                                              | 仅 `FlashStorm` 会弹系统通知；`StormWarning`/`Worsening` 仅在 RealtimeDataCard 与 WAPS 文案中展示。           |

## 3. 实现方案（MVP）

### 3.1 3h 内下降 1.5–2 hPa 的告警/提示

- **洞察引擎（WeatherInsightsEngine）**
  - 在 **buildPressureTrendInsight** 与 **buildOverviewSummary3h / buildOverviewSummary** 中，增加一档：**3h ΔP 在 [-2, -1.5] 区间** 时：
    - 严重度：`Attention`。
    - 文案：突出「雷雨或大风可能即将到来，请留意」或与现有「天气可能转差」合并为「近 3 小时气压下降约 1.5–2 hPa，雷雨或大风可能即将到来，请留意」。
  - 实现方式：在现有 `delta3h`/`ehr3h` 分支中增加对 **-2 &lt; delta3h ≤ -1.5** 的单独分支（或与现有 -1.5 档位对齐，保证 1.5–2 hPa 一定落在「注意」且文案明确提到雷雨/大风）。
- **Waps 实时告警（WapsLogic + UI）**
  - 将 **WORSENING_DELTA_THRESHOLD** 从 **-2** 改为 **-1.5**，使「3h 下降 ≥1.5 hPa」即触发「天气恶化，阴雨/大风可能」，与用户描述一致。若担心告警过频，可仅改洞察文案，不动 Waps 阈值；建议先改阈值，观察反馈再收窄。
- **通知**：本期不新增系统通知（保持仅 FlashStorm 强通知）；Worsening 仍以卡片/洞察提示为主。

### 3.2 24 小时气压分析

- 在 **buildPressureTrendInsight** 中：
  - 计算 **ΔP(24h)**：`deltaOverWindow(last24h, nowSec, WINDOW_24H_SEC)`（已有 `deltaOverWindow`，可复用）。
  - 计算 **24h 内最低/最高气压**：在 last24h 有效气压中取 min/max（及可选：出现的大致时间或「前半段/后半段」）。
  - **24h 描述逻辑（简短、可解释）**：
    - 若 24h 有效点 &lt; 2：不写 24h 结论，保持现状。
    - 若 ≥2：在 summary 中增加一句 24h 描述，例如：
      - 「24 小时：气压下降 X hPa，整体偏低压」/「24 小时：气压回升 X hPa，天气趋稳」；
      - 若可简单判断「先跌后涨」（例如 24h 内最低点不在首尾，且首、尾气压均高于最低点），则增加「24 小时内曾明显下降后回升，波动较大」类表述。
  - **metrics**：增加 **ΔP(24h)**、**Pmin(24h)**、**Pmax(24h)**（单位 hPa）；若需可加「24h 变幅」= Pmax - Pmin。
  - **scope**：为「气压趋势与降水倾向」卡片增加 **Scope24h**，与冷空气卡片一致，便于 UI 展示「24 小时口径」标签。

### 3.3 与现有逻辑的关系

- 不改变「冷空气/锋面」等其它卡片的 24h 逻辑。
- 不改变 EHR 动态矩阵（10–30 min 突发雷雨等）的阈值，仅补充 3h ΔP 1.5–2 hPa 的提示档位与 24h 分析展示。
