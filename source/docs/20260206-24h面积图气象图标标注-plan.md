# 24 小时面积图气象图标标注 - 开发计划

## 1. 需求背景

在 24 小时趋势面积图上，希望按时间标注气象事件，并在**时间轴下方**显示对应图标，便于一眼看出何时出现：

- 气压陡然下降 → 降水/雷雨可能
- 气压陡然升高 → 转晴
- 冷空气/锋面迹象
- 起雾/结露风险
- 进入室内/干暖环境（温升湿降且气压稳定）

## 2. 实现方案（已完成）

### 2.1 数据与计算

- **ChartWeatherEvent**（`data/weather/ChartWeatherEvent.kt`）：事件类型枚举 + 数据类 `(timestampSec, type, endSec?)`。`endSec` 为 null 表示单点，否则表示区间 [timestampSec, endSec]。
- **WeatherChartEvents**（`utils/WeatherChartEvents.kt`）：从 24h 记录计算事件列表，再**按区间合并**（同类型、时间差 ≤ 2h 合并为一个区间），最终每个区间只对应一个图标。
  - 1h 滑动窗口：ΔP < -2 hPa → 降水可能；ΔP > 2 hPa → 转晴。
  - 1h 滑动窗口：ΔT ≥ +1.5°C 且 ΔRH ≤ -8% 且 |ΔP| ≤ 0.6 hPa → 进入室内/干暖环境。
  - 6h 滑动窗口：ΔT ≤ -6°C 且 |ΔRH| ≥ 15% → 冷空气/锋面。
  - 逐点：RH ≥ 90% 且温露差 ≤ 2°C → 起雾/结露（邻近 2h 内合并为一个图标）。

### 2.2 图表展示

- **LineChart** 增加参数 `chartEvents: List<ChartWeatherEvent> = emptyList()`。
- 在图表区域下方（时间轴下方）增加一行（高度 28.dp），按**区间中点**放置图标（一个区间一个图标）：
  - 降水可能 → `WaterDrop`
  - 转晴 → `WbSunny`
  - 冷空气/锋面 → `AcUnit`
  - 起雾/结露 → `Cloud`
  - 室内/干暖环境 → `Home`
- **Tooltip**：拖拽时若选中时间落在某区间内则显示该区间，文案为「HH:mm–HH:mm 类型」；否则显示 60 分钟内最近事件。

### 2.3 点击图标高亮区间（已完成）

- 图标可点击：点击某图标后，图表上该事件对应时间区间以**半透明竖条带**高亮，且该图标用 `primaryContainer` 背景与更高不透明度区分。
- 再次点击同一图标取消高亮；点击其他图标则高亮切换到对应区间。
- 数据源变化（chartEvents 变化）时自动清除高亮。

### 2.4 调用处

- **TrendChartCard**：`chartEvents = remember(records) { WeatherChartEvents.compute(records) }`。
- **HistoryScreen**（24h 图表）：同上，用 `last24HoursRecords` 计算并传入。

## 4. 补充优化（2026-02-06）

### 4.1 问题描述

用户反馈在 24h 图中出现明显「温度陡升、湿度陡降」时，时间轴下方**未显示**“小房子（进入室内/干暖环境）”图标。

排查后确认：`LineChart` 已支持 `INDOOR_WARM_DRY -> Home` 的渲染；问题主要出在事件计算规则对气压数据的依赖。

### 4.2 根因

当前 `INDOOR_WARM_DRY` 规则为了避免误判，要求 **1h 起点和终点都必须有有效气压**，否则直接跳过不产出事件。

在部分记录中，“当前点有气压，但 1h 前附近没有有效气压点/气压为 0”，会导致看起来符合温湿突变的场景也不会生成事件，从而不显示图标。

### 4.3 方案（最小 MVP）

- **气压条件改为可选**：
  - 如果能取到 1h 起点与终点的有效气压：仍要求 \(|ΔP| ≤ 0.6\) 以抑制误判
  - 如果取不到起止气压：允许仅按「温升 + 湿降」触发 `INDOOR_WARM_DRY`
