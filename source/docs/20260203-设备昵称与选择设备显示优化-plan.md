# 设备昵称与选择设备显示优化 - 开发计划

## 需求背景

- 在首页「设备配置」弹窗（设置齿轮打开的 ConfigModal）中，允许用户为当前连接设备设置昵称。
- 昵称与设备的关联以**蓝牙地址（macAddress）**为唯一匹配键。
- 在「选择设备」弹窗中：
  - **主标题**：优先显示昵称，若无昵称则显示蓝牙名称。
  - **第二行**：始终显示蓝牙地址；若**已配置昵称**，则在蓝牙地址后面用与固件号相同的字体大小（bodySmall）、括号形式追加显示蓝牙名称，例如：`XX:XX:XX:XX:XX:XX (Panda-Pro-X1)`。
- **首页设备状态**：顶部状态栏（StatusBar）中的设备名称也优先显示昵称，无昵称时再显示蓝牙名称。

## 实现方案

### 1. 数据层

- **Device 实体**（`data/model/Device.kt`）
  - 新增字段：`nickname: String? = null`（用户设置的昵称；新建/旧数据默认为 null）。
- **AppDatabase**
  - 数据库版本号 +1（当前为 7，改为 8）。
  - 新增 Migration 7→8：对 `devices` 表执行 `ALTER TABLE devices ADD COLUMN nickname TEXT DEFAULT NULL`。
- **DeviceDao**
  - 新增方法：`updateNickname(address: String, nickname: String?)`，按 `macAddress` 更新昵称。

### 2. 首页设备配置（ConfigModal）

- 在「设备信息」区域（固件版本、存储记录、时间同步等上方或下方）增加**设备昵称**输入项：
  - 单行输入框，placeholder 如「输入设备昵称（选填）」。
  - 支持清空（空字符串表示未设置昵称）。
- ConfigModal 新增入参：
  - `currentNickname: String?`：当前设备的昵称（用于初始化输入框）。
  - `onSaveNickname: (String?) -> Unit`：保存时回调，传入昵称（可为 null 或空字符串）。
- 保存逻辑：用户点击「保存」时，除原有采集间隔保存外，若昵称有变更则调用 `onSaveNickname`（可与现有 onSave 一起触发，由 ViewModel 统一写库）。

### 3. ViewModel 与 MainScreen

- **MainViewModel**
  - 新增：`updateDeviceNickname(address: String, nickname: String?)`，内部调用 `deviceDao.updateNickname(address, nickname)`。
  - 当前设备信息：不新增额外 Flow，由 MainScreen 通过已有 `savedDevices` + `deviceAddress`（或 `viewingDeviceAddress`）在列表中查找当前 Device，得到 `nickname` 传入 ConfigModal。
- **MainScreen**
  - 收集 `savedDevices` 与当前设备地址（如 `deviceAddress` 或 ViewModel 暴露的 viewingDeviceAddress）。
  - 根据地址从 `savedDevices` 中取当前 `Device`，将 `device?.nickname` 传给 ConfigModal 的 `currentNickname`。
  - 在 ConfigModal 的保存/回调中调用 `viewModel.updateDeviceNickname(currentAddress, newNickname)`。

### 4. 选择设备弹窗（DeviceSelectionDialog）

- **SavedDeviceItem** 展示逻辑：
  - **主标题（第一行）**：`displayName = device.nickname?.takeIf { it.isNotBlank() } ?: device.name`（优先昵称，否则蓝牙名）。
  - **第二行**：
    - 始终显示 `device.macAddress`。
    - 若 `device.nickname?.isNotBlank() == true`，则在地址后追加 ` (${device.name})`，样式与固件号一致：`MaterialTheme.typography.bodySmall`、`color = MaterialTheme.colorScheme.onSurfaceVariant.copy(alpha = 0.7f)`，与现有固件号展示风格统一。

### 5. 设备管理页（DeviceManagementScreen）

- 列表项主标题与「选择设备」保持一致：优先显示昵称，无昵称时显示蓝牙名（`device.nickname?.takeIf { it.isNotBlank() } ?: device.name`），避免两处展示逻辑不一致。

### 6. 其他说明

- 新添加设备时，`Device` 构造仍使用 `name = device.name ?: "未知设备"`（蓝牙名），`nickname = null`，无需改动 saveDevice 逻辑。
- 删除设备时无需单独处理昵称（随记录一起删除）。
