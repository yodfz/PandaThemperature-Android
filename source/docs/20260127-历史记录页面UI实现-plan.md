# 历史记录页面UI实现开发计划

## 需求背景

根据 `UI/history.html` 的设计效果，需要重新实现历史记录页面的UI，使其与HTML设计保持一致。

## 现状分析

1. **已有实现**：
   - `HistoryScreen.kt` 已有基础结构
   - `HistoryItem` 组件已存在，但样式不符合HTML设计
   - 已有视图切换功能（列表/图表）
   - 已有下拉刷新功能

2. **需要改进**：
   - 顶部标题栏样式（传感器图标 + 标题）
   - 视图切换按钮样式（SegmentedControl风格）
   - 列表项样式完全重新设计
   - 添加"更早记录"分隔标签
   - 添加底部刷新按钮
   - 添加最后同步时间显示

## 实现方案

### 1. 顶部标题栏改造
- 添加传感器图标（Material Icons: sensors，FILL=1）
- 标题改为"历史数据记录明细"
- 使用半透明背景，带模糊效果（backdrop blur）
- 移除菜单按钮，改为在视图切换区域处理

### 2. 视图切换按钮
- 实现类似SegmentedControl的切换按钮
- 两个选项：列表、图表
- 选中状态有背景色和阴影
- 使用Material Icons图标

### 3. 列表项重新设计（HistoryItem组件）
**布局结构**：
- 左侧：时间戳 + 传感器名称和连接状态
- 右侧：温度和湿度 + 箭头图标

**样式细节**：
- 时间戳：mono字体，13px，格式 "yyyy-MM-dd HH:mm:ss"
- 传感器名称：
  - 绿色圆点（已连接）或灰色圆点（未连接）
  - 传感器名称 + "(已连接)" 或仅传感器名称
- 温度：红色 (#FF5252)，18px，粗体，格式 "XX.X°C"
- 湿度：青色 (#00E5FF)，11px，粗体，格式 "XX% RH"
- 右侧箭头图标（chevron_right）
- 斑马纹背景（交替：正常背景色 / 浅色背景 #151d26）

### 4. "更早记录"分隔标签
- 当数据跨越较长时间（如超过24小时）时显示分隔
- 样式：灰色背景，小号大写文字，带边框

### 5. 底部刷新按钮
- 固定位置，右下角（bottom: 24dp, right: 24dp）
- 圆形，主色背景，白色图标
- 点击触发下拉刷新

### 6. 最后同步时间显示
- **在下拉刷新时显示**，没有下拉时隐藏
- 蓝牙图标 + "最后同步：X分钟前"
- 需要计算最后同步时间（从历史记录获取最新记录的时间）
- 集成到 SwipeRefresh 的下拉指示器中

### 7. 颜色定义
- 温度颜色：#FF5252（temp-red）
- 湿度颜色：#00E5FF（hum-cyan）
- 斑马纹背景：#151d26（row-stripe）

## 技术细节

### 连接状态判断
- 根据记录的时间戳判断：如果记录时间在连接期间，显示"已连接"
- 或者根据当前连接状态和记录时间判断

### 时间格式化
- 使用 `SimpleDateFormat` 格式化时间戳
- 格式："yyyy-MM-dd HH:mm:ss"
- 使用 mono 字体族

### 最后同步时间计算
- 从历史记录中获取最新记录的时间戳
- 计算与当前时间的差值
- 显示为"X分钟前"、"X小时前"等

### 分隔标签逻辑
- 遍历记录列表，检测时间间隔
- 如果相邻记录时间间隔超过24小时，显示分隔标签

## 注意事项

1. **性能优化**：
   - 使用 LazyColumn 确保列表性能
   - 避免在列表项中进行复杂计算

2. **主题适配**：
   - 确保颜色在深色主题下正确显示
   - 使用 MaterialTheme 的颜色系统

3. **数据一致性**：
   - 确保传感器名称和连接状态正确显示
   - 处理时间戳为0的情况（未同步时间）

4. **用户体验**：
   - 保持下拉刷新功能
   - 保持自动加载更多功能
   - 确保交互流畅
