# 最高最低温度读取失败重试与手动同步提示

## 需求背景

用户希望：

1. **最高最低温度读取失败时**：先等历史同步结束，再自动重试一次同步。
2. **若重试后仍失败**：在显示最高/最低温度的区域提示用户「点击尝试手动同步」。
3. **默认无数据时**：若没有最高/最低温度数据，该区域不显示任何文字（不显示 "--" 等占位）。

## 实现方案

### 1. ViewModel 逻辑（MainViewModel）

- **可同步调用的读取方法**：抽一个内部 `readMaxMinTemperatureSync(): Boolean`（suspend），在协程内执行现有读取+重试逻辑，返回是否成功。现有对外 `readMaxMinTemperature()` 改为在 `viewModelScope.launch` 里调用该 sync 方法；若成功则清除「需手动同步」状态。
- **首次读取失败标记**：在 `initializeDevice()` 中，若设备支持最高最低温度且 `readMaxMinTemperatureSync()` 返回 `false`，设置成员变量 `maxMinTempReadFailed = true`。
- **历史同步结束后重试**：在 `finishHistoryFetch()` 末尾（在 `shouldClearState` 分支内，恢复订阅、刷新 UI 等之后），若 `maxMinTempReadFailed == true`，再调用一次 `readMaxMinTemperatureSync()`；若仍返回 `false`，则设置 `_maxMinTempNeedManualSync.value = true`；若成功则设为 `false`。最后将 `maxMinTempReadFailed = false`。
- **新状态**：增加 `_maxMinTempNeedManualSync: MutableStateFlow<Boolean>`，对外暴露 `maxMinTempNeedManualSync: StateFlow<Boolean>`。在 `resetConnectionState()` 中重置为 `false`。
- **手动同步成功**：在 `readMaxMinTemperatureSync()` 成功写入 `_maxTemperature`/`_minTemperature` 等时，同时设置 `_maxMinTempNeedManualSync.value = false`（公开的 `readMaxMinTemperature()` 通过调用 sync 方法间接触发）。

### 2. UI 逻辑（RealtimeDataCard + MainScreen/HomeScreen）

- **是否显示区域**（满足其一即显示该区域）：
  - 有最高或最低温度数据（`maxTemperature != null || minTemperature != null`），或
  - 需要手动同步（`maxMinTempNeedManualSync == true`，且设备支持最高最低）。
- **无数据且不需手动同步**：不渲染最高/最低温度区域（不显示任何文字）。
- **无数据但需手动同步**：显示一句提示「点击尝试手动同步」（可点击触发 `onRefreshMaxMinTemp`），不显示「最高: --°C」等。
- **有数据**：保持现有展示（最高/最低温度与时间），点击仍触发 `onRefreshMaxMinTemp`。

为区分「不支持」与「支持但无数据」，RealtimeDataCard 需要知道「是否支持最高最低」：增加参数 `isMaxMinTempSupported: Boolean`。仅当 `isMaxMinTempSupported == true` 时，才根据上面规则显示区域或「点击尝试手动同步」；为 false 时整个区域不显示。

MainScreen：从 ViewModel 收集 `isMaxMinTempSupported`、`maxMinTempNeedManualSync`，传给 HomeScreen，再传给 RealtimeDataCard。

### 3. 涉及文件

- `app/src/main/java/com/example/pandatemperature/ui/viewmodel/MainViewModel.kt`
  - 新增 `readMaxMinTemperatureSync()`，`readMaxMinTemperature()` 改为调用它并清除 needManualSync；
  - 新增 `_maxMinTempNeedManualSync` / `maxMinTempNeedManualSync`；
  - `initializeDevice()` 中根据 sync 结果设 `maxMinTempReadFailed`；
  - `finishHistoryFetch()` 中在历史同步结束后根据 `maxMinTempReadFailed` 重试并设置 `maxMinTempNeedManualSync`；
  - `resetConnectionState()` 中重置 `maxMinTempNeedManualSync` 与 `maxMinTempReadFailed`。
- `app/src/main/java/com/example/pandatemperature/ui/components/RealtimeDataCard.kt`
  - 增加参数 `isMaxMinTempSupported`、`maxMinTempNeedManualSync`；
  - 仅当支持时渲染区域；无数据且 needManualSync 时只显示「点击尝试手动同步」；有数据时保持现有展示。
- `app/src/main/java/com/example/pandatemperature/ui/screen/MainScreen.kt`
  - 收集 `isMaxMinTempSupported`、`maxMinTempNeedManualSync`，并传给 HomeScreen → RealtimeDataCard。
