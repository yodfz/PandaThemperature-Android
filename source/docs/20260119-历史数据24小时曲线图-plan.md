# 历史数据24小时温湿度曲线图开发计划

## 需求背景

用户希望在历史数据界面中，通过右上角菜单新增一个功能，可以查看最近24小时的温湿度曲线图。点击后新开页面显示最近24小时温湿度的折线图，方便用户直观地查看温湿度变化趋势。

## 实现方案

### 1. 数据获取
- 在 `MainViewModel` 中添加获取最近24小时数据的方法
- 使用数据库 DAO 的 `getRecordsByTimeRange` 方法
- 计算当前时间往前推24小时的时间范围
- 通过 StateFlow 提供数据流，支持响应式更新

### 2. 折线图组件设计
- 创建可复用的 `LineChart` 组件，使用 Compose Canvas 绘制
- 支持双 Y 轴：左侧显示温度（摄氏度），右侧显示湿度（百分比）
- 温度折线使用红色，湿度折线使用蓝色
- X 轴显示时间（小时:分钟格式）
- 添加图例说明
- 支持数据点标记（可选）

### 3. 图表页面设计
- 创建 `ChartScreen` 页面组件
- 显示页面标题："最近24小时温湿度曲线"
- 使用折线图组件展示数据
- 处理空数据状态（无数据时显示提示）
- 添加返回按钮（如需新页面导航）

### 4. 菜单集成
- 在 `HistoryScreen` 的右上角菜单中添加新选项
- 菜单项文字："查看最近24小时曲线图"
- 点击后触发导航或显示图表页面

### 5. 导航方案
- 由于当前使用 Tab 导航，图表页面可以通过以下方式展示：
  - 方案A：在 MainScreen 中添加一个状态，临时显示图表页面覆盖当前内容
  - 方案B：使用 Dialog/Modal 全屏显示图表
  - 方案C：在 HistoryScreen 内部通过状态切换显示图表（推荐，最简单）
  
采用方案C：在 HistoryScreen 中通过状态管理，切换显示列表或图表视图

### 宽高比修复（2026-01-19 第三次优化）

#### 需求背景
用户反馈图表呈现全屏竖向长方形，Y轴比X轴长，不符合正常图表的显示方式。

#### 问题分析
- 使用 `Modifier.weight(1f)` 导致图表占满整个可用高度
- 在竖屏手机上，可用高度远大于宽度，导致图表变成竖向长方形
- 正常图表应该是横向长方形，Y轴（高度）应该比X轴（宽度）短

#### 修复方案
- 使用 `aspectRatio(16f / 9f)` 限制图表宽高比为 16:9
- 宽度使用 `fillMaxWidth()` 占满可用宽度
- 高度根据宽度和宽高比自动计算
- 确保图表始终保持横向长方形，Y轴比X轴短

### 触摸交互功能（2026-01-19 第四次优化）

#### 需求背景
用户希望在图表上增加触摸交互功能，触摸时显示竖线指示器，并在图例下方显示对应时间点的温度、湿度信息。为了避免触摸时布局重排，信息栏需要固定高度，即使未触摸时也保留空白行。

#### 实现方案
1. **触摸手势处理**
   - 在Canvas上添加`pointerInput`，使用`detectDragGestures`检测触摸和拖拽
   - 将触摸X坐标映射到最近的数据点索引
   - 使用`remember { mutableStateOf<Int?>(null) }`保存选中状态
   - **松手后保留最后一次选中**（不清理状态）

2. **信息栏设计（固定高度）**
   - 在图例下方添加固定高度的信息栏（32.dp）
   - 显示格式：时间 | 温度（带颜色块）| 湿度（带颜色块）
   - 未选中时显示`--`占位，选中时显示实际数据
   - 固定高度确保触摸时不会导致布局重排

3. **竖线指示器**
   - 当有选中数据点时，在图表上绘制竖线（crosshair）
   - 竖线从顶部到底部，与选中点的X坐标对齐
   - 使用半透明颜色，不遮挡数据
