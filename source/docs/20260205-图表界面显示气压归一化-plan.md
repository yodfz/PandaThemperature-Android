# 图表界面显示气压（归一化）开发计划

## 需求背景

用户希望在历史数据的「曲线图」界面中显示气压曲线。气压原始值约 980–1050 hPa，与温度、湿度量纲差异大，若直接使用原始值会压扁曲线，因此对气压做归一化后再绘图。

## 实现方案

### 1. 气压归一化方式

- **相对气压（ΔhPa）**：取当前 24 小时序列内有效气压的最小值 `P_min`，绘图使用 `pressure - P_min`。
- 效果：Y 轴为「相对 hPa」，数值在 0 ～数十 hPa 内，趋势与原始气压一致，便于与温湿度在同一图表内展示。
- 仅当 `records` 中存在有效气压（`pressure != null && pressure > 0`）时才绘制气压线；无有效气压时与现有一致，不显示气压图例与信息栏。

### 2. 图表与交互

- **LineChart**（`ui/components/LineChart.kt`）：
  - 在现有双 Y 轴（左温度、右湿度）基础上，增加**气压曲线**（不增加第三根 Y 轴）。
  - 气压使用与湿度相同的绘图高度 `chartHeight`，Y 轴映射：`normalized = pressure - minPressure`，`ratio = normalized / maxNormalized`（若 `maxNormalized == 0` 则整条线在底部）。
  - 气压线颜色：与温湿度区分，采用一种新颜色（如橙色/紫色）。
  - 图例：有有效气压时增加「气压 (ΔhPa)」图例。
  - 信息栏：有有效气压时增加选中点的气压显示，格式为真实值 `XXX.X hPa`，括号内可带 `ΔX.X` 便于理解。

### 4. 架构与复用

- 不新增 ViewModel 或数据层；`TemperatureRecord` 已含 `pressure: Float?`，`last24HoursRecords` 已包含气压，直接复用。
- 归一化与绘图逻辑仅在 `LineChart` 内完成，避免数据泥团与分散逻辑。
