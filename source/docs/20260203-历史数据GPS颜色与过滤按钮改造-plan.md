# 历史数据 GPS 颜色与过滤按钮改造 - 开发计划

## 需求背景

1. **GPS 颜色统一**：历史数据列表页的 GPS 数据显示颜色与首页不一致，需要改为与首页一致的蓝色。
2. **时间筛选交互改造**：将当前展开型时间筛选器改为「过滤按钮 + 弹窗菜单」的形式：
   - 在刷新按钮上方增加过滤按钮
   - 点击过滤按钮弹出过滤选项菜单
   - 有筛选条件时，过滤按钮高亮显示

## 现状分析

### GPS 颜色

- **首页 (HistoryCard.kt)**：`MaterialTheme.colorScheme.primary.copy(alpha = 0.7f)`（蓝色 primary）
- **历史数据列表 (HistoryItem.kt)**：`Color(0xFF4CAF50).copy(alpha = 0.8f)`（绿色）
- **需要**：HistoryItem 的 GPS 改为 `PrimaryBlue` 或 primary，与首页一致

### 时间筛选

- **当前**：列表/图表切换下方有展开型 `TimeFilterSection`（起始/结束日期时间选择）
- **目标**：移除展开区域，改为「过滤按钮 + 弹窗」：
  - 过滤按钮在 FAB（刷新按钮）上方
  - 点击弹出过滤菜单（ModalBottomSheet 或 DropdownMenu）
  - 有筛选时过滤按钮高亮（PrimaryBlue 图标/背景）

## 实现方案

### 1. GPS 颜色修改

- **文件**：`app/src/main/java/com/example/pandatemperature/ui/components/HistoryItem.kt`
- **改动**：将两处 GPS 文字颜色从 `Color(0xFF4CAF50).copy(alpha = 0.8f)` 改为 `PrimaryBlue.copy(alpha = 0.8f)`，与首页蓝色一致

### 2. 过滤按钮与弹窗改造

- **文件**：`app/src/main/java/com/example/pandatemperature/ui/screen/HistoryScreen.kt`
- **布局**：
  - 移除 `TimeFilterSection` 展开区域（列表/图表切换下方）
  - 在 FAB 区域改为垂直排列两个按钮：上方过滤按钮、下方刷新按钮
  - 过滤按钮：使用 `Icons.Filled.FilterList` 或 `Icons.Filled.Tune`
  - 有筛选时：过滤按钮使用 PrimaryBlue 高亮（图标 tint 为 PrimaryBlue）
  - 无筛选时：过滤按钮使用默认灰色
- **弹窗**：点击过滤按钮弹出 `ModalBottomSheet`，内部复用/迁移现有 `TimeFilterSection` 的日期时间选择逻辑
- **保留**：`TimeFilterSection` 抽成可复用组件，在 BottomSheet 内使用

## 技术要点

- 使用 `ModalBottomSheet` 承载过滤选项（日期时间选择器需要足够空间）
- FAB 区域使用 `Column` 垂直排列：Filter FAB 在上，Refresh FAB 在下
- 过滤逻辑与 ViewModel 的 `setHistoryTimeFilter`、`resetHistoryTimeFilter` 保持不变
