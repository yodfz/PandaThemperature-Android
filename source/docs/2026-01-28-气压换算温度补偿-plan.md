# 气压换算温度补偿 - 开发计划

## 需求背景

用户询问气压换算是否需要增加温度补偿。
目前应用中使用的是标准大气压高度公式（Standard Atmosphere），该公式假设标准温度（15°C）。
为了提高海拔计算的准确性，建议引入实时温度进行补偿，使用测高公式（Hypsometric formula）的变体。

## 现有逻辑

`WeatherUtils.kt`:
```kotlin
fun calculateAltitude(pressurehPa: Float): Int {
    val p0 = 1013.25f
    // 简单海拔公式：h = 44330 * (1 - (p/p0)^(1/5.255))
    return (44330.0 * (1.0 - (pressurehPa / p0).pow(1.0f / 5.255f))).toInt()
}
```

## 改进方案

### 1. 更新 `WeatherUtils.kt`

修改 `calculateAltitude` 函数，增加可选参数 `temperatureCelsius: Float?`。

**新公式**：
如果提供温度，使用温度补偿公式：
$$h = \frac{((\frac{P_0}{P})^{\frac{1}{5.257}} - 1) \times (T + 273.15)}{0.0065}$$

如果不提供温度，保持原有标准公式。

### 2. 更新 UI 组件

在显示海拔的地方，传入当前温度。
- `RealtimeDataCard.kt`
- `HistoryCard.kt`
