# 历史数据传输阻止息屏

## 需求背景

在历史数据传输过程中，需要保持屏幕常亮，防止传输过程中因为息屏导致蓝牙传输中断或用户无法看到进度。

## 实现方案

使用 Android 的 `FLAG_KEEP_SCREEN_ON` 机制（无需额外权限）：

通过 Compose 的 `LocalView` 动态设置 `keepScreenOn` 属性，当 `isFetchingHistory = true` 时保持屏幕常亮。
