# 界面尺寸优化和自动订阅开发计划

## 需求背景

用户反馈：

1. 界面元素太大，需要缩小尺寸使其更紧凑
2. 不需要使用阴影（当前已无阴影，需保持）
3. 打开 APP 自动订阅所有更新，不需要手动订阅按钮

## 实现方案

### 一、界面尺寸优化

1. **卡片内边距缩小**

   - 从 20dp 减少到 12-14dp
   - 卡片间距从 16dp 减少到 12dp

2. **温湿度显示区域缩小**

   - 数值字体：从 `displayMedium` 改为 `displaySmall` 或 `headlineLarge`
   - 单位字体：从 `titleLarge` 改为 `titleMedium`
   - 卡片内边距：从 24dp 减少到 16dp
   - 标签字体：保持 `bodyMedium` 但可适当缩小

3. **按钮尺寸缩小**

   - 按钮高度：从 52dp 减少到 40dp
   - 按钮文字：保持当前大小或略微缩小

4. **状态栏优化**

   - 内边距：从 18dp/16dp 减少到 12dp/10dp
   - 状态指示点：从 12dp 减少到 10dp

5. **历史数据卡片**

   - 内边距：从 20dp 减少到 14dp
   - 列表项高度：适当缩小
   - 按钮高度：从 52dp 减少到 40dp

6. **整体间距优化**
   - 卡片间距：从 16dp 减少到 12dp
   - 元素间距：统一缩小 20-30%

### 二、自动订阅功能

1. **移除订阅按钮**

   - 从 `RealtimeDataCard` 移除"订阅实时数据"按钮
   - 从 `HomeScreen` 移除 `onSubscribe` 参数

2. **确保自动订阅**
   - 在 `MainViewModel.initializeDevice()` 中已实现自动订阅
   - 确保连接成功后自动订阅逻辑可靠

## 注意事项

1. **无阴影设计**：保持当前无阴影的边框+渐变设计
2. **尺寸一致性**：确保所有卡片、按钮、间距统一缩小
3. **可读性**：缩小尺寸的同时保持文字清晰可读
4. **自动订阅**：确保连接成功后自动订阅，无需用户操作
