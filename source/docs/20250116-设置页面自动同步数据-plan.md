# 设置页面自动同步数据 - 开发计划

## 需求背景

当前应用在设置页面中，用户需要手动点击"读取间隔"和"读取状态"按钮才能获取最新的时间间隔和设备状态信息。为了提高用户体验，需要在进入设置页面时，如果设备已连接，自动读取并同步这些数据，无需用户手动操作。

## 实现方案

### 1. 实现位置
- 文件：`app/src/main/java/com/example/pandatemperature/ui/screen/SettingsScreen.kt`
- 使用 `LaunchedEffect` 监听连接状态变化

### 2. 实现逻辑
- 在 `SettingsScreen` 中添加 `LaunchedEffect(connectionState)` 来监听连接状态
- 当设备连接状态为已连接（非 `Disconnected`）时：
  1. 延迟 200ms 确保页面加载完成
  2. 自动调用 `viewModel.readInterval()` 读取时间间隔
  3. 延迟 300ms 确保操作完成
  4. 自动调用 `viewModel.readStatus()` 读取设备状态
- 保留手动读取按钮功能，作为刷新数据的备选方式

### 3. 技术细节
- 使用 `LaunchedEffect(connectionState)` 确保连接状态变化时触发
- 使用 `kotlinx.coroutines.delay()` 实现操作间的延迟
- 复用现有的 `readInterval()` 和 `readStatus()` 方法，避免代码重复
- 确保只在设备已连接时才执行自动读取操作

### 4. 参考实现
参考历史数据页面的实现方式（`MainScreen.kt` 中使用 `LaunchedEffect` 自动加载数据）

## 注意事项

1. 延迟时间要合适，太短可能导致设备响应不及时，太长会影响用户体验
2. 确保异常处理完善，即使自动读取失败也不影响其他功能
3. 保留手动读取按钮，方便用户主动刷新数据
4. 避免重复读取，只在连接状态变化为已连接时触发一次
