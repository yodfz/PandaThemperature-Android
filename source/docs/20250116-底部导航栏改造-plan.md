# 底部导航栏改造开发计划

## 需求背景

用户希望将当前的顶部TabRow（标签栏）改为底部导航栏（NavigationBar），以提供更符合现代Android应用设计规范的导航体验。

## 实现方案

### 一、移除顶部TabRow

1. **保留StatusBar**
   - StatusBar（状态栏）继续保留在topBar中
   - 移除TabRow相关代码

2. **简化topBar结构**
   - topBar只包含StatusBar
   - 移除TabRow的Column包装

### 二、添加底部NavigationBar

1. **使用Material3 NavigationBar组件**
   - 在Scaffold的bottomBar参数中添加NavigationBar
   - 使用NavigationBarItem替代原来的Tab

2. **导航项配置**
   - 首页：使用Icons.Default.Home图标
   - 历史数据：使用Icons.Default.History图标
   - 设置：使用Icons.Default.Settings图标
   - 每个导航项包含图标和文字标签

3. **状态管理**
   - 继续使用selectedTabIndex管理当前选中的导航项
   - 保持原有的页面切换逻辑不变

### 三、布局调整

1. **内容区域padding调整**
   - 移除底部padding的手动计算（因为NavigationBar会自动处理）
   - 确保内容不被底部导航栏遮挡
   - 保持顶部StatusBar的padding处理

2. **视觉优化**
   - 确保NavigationBar与应用主题风格一致
   - 保持原有的渐变背景效果
