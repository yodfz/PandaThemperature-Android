# UI 配色优化计划

## 问题反馈
用户反馈默认配色存在问题，感觉偏向“粉红色”（实际为深色模式下的低饱和度橙色 `Deep Orange-200` / `0xFFFFAB91`）。

## 优化方案
为了提供更专业、科技感更强的视觉体验，同时避免“粉红”的视觉误解，决定调整应用的主题色系。

### 配色调整
采用 **科技蓝 (Tech Blue)** 作为主色调，**温度橙 (Temperature Orange)** 作为强调色。

| 颜色角色 | 原色值 (Old) | 新色值 (New) | 说明 |
| :--- | :--- | :--- | :--- |
| **Primary (主色)** | `0xFFFFAB91` (Orange-200) | `0xFF90CAF9` (Blue-200) | 用于按钮、选中状态、TopBar 等核心 UI 元素，由粉橙色改为清爽的蓝色。 |
| **Accent/Tertiary (强调)** | `0xFF90CAF9` (Blue-200) | `0xFFFFAB91` (Orange-200) | 用于次要高亮，交换了原来的主色和强调色，保留温度的暖色特征但降低占比。 |
| **Primary (Light)** | `0xFFFF5722` (Orange-700) | `0xFF1976D2` (Blue-700) | 浅色模式对应调整（虽然目前应用强制深色模式）。 |

### 影响范围
- 全局按钮颜色
- 顶部应用栏（TopAppBar）
- 开关（Switch）选中状态
- 悬浮按钮（FloatingActionButton）
- 文本框光标和选中颜色

### 预期效果
应用整体色调将从“暖色/粉色”转变为“冷色/科技蓝”，视觉上更加冷静、专业，符合工具类应用的定位。温度数值本身显示的红色/橙色保持不变。
