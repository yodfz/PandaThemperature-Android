# 首页历史数据表格化改造开发计划

## 需求背景

用户反馈首页历史数据区域的展示存在问题：
1. 当前使用固定高度（300dp）的 LazyColumn，内部滚动，体验不佳
2. 当前样式较为复杂（渐变背景、多边框），不够简洁
3. 希望改为表格样式，更清晰易读

## 需求详情

1. **滚动方式改进**：移除固定高度限制，让历史数据跟随页面整体滚动（使用 Column 布局）
2. **表格化样式**：
   - 添加表头行（时间 | 温湿度）
   - 数据行采用斑马纹（单双行不同背景色）
   - 温湿度在同一列中上下换行显示
   - 移除分割线，保持简洁
   - 时间列左对齐，温湿度列右对齐

## 实现方案

### 1. 布局结构调整

**HistoryCard.kt 修改：**
- 将 `LazyColumn` 改为 `Column`（父页面已有 verticalScroll）
- 移除 `.height(300.dp)` 限制
- 移除 LazyColumn 相关的导入和逻辑

### 2. 表格样式实现

**表头行：**
- 使用 Surface 或 Box，深色背景（MaterialTheme.colorScheme.surfaceVariant）
- 两列布局：时间 | 温湿度
- 文字颜色为 onSurfaceVariant，加粗

**数据行（HistoryItem 重构）：**
- 使用 Row 布局，两列
- 第一列：时间（左对齐）
- 第二列：Column 布局，温度在上，湿度在下（右对齐）
- 根据索引判断单双行，应用不同背景色
  - 单行：MaterialTheme.colorScheme.surface
  - 双行：MaterialTheme.colorScheme.surfaceVariant.copy(alpha = 0.3f)

### 3. 样式细节

- 移除渐变背景（Brush.horizontalGradient）
- 移除复杂的边框和圆角
- 保持适当的内边距（padding）
- 使用 Material3 的颜色系统
