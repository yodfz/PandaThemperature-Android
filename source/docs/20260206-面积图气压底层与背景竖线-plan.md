# 面积图气压底层与背景竖线 - 开发计划

## 1. 需求背景

- 面积图中气压线：整体透明度减半，并作为最底层显示（不盖在温湿度上）。
- 背景格子：竖线数量增加一倍。

## 2. 实现方案

### 2.1 气压线

- **绘制顺序**：在 `LineChart.kt` 的 Canvas 中，将「绘制气压面积图」整块移动到「绘制温度面积图」之前，即：网格 → 气压面积+线 → 温度面积+线 → 湿度面积+线 → 选中竖线/亮点等。这样气压在最下层。
- **透明度/2**：
  - 气压颜色定义处：`pressureColor`、`pressureGradientStart`、`pressureGradientEnd` 的 alpha 各减半（当前约 1.0 / 0.6 / 0.2 → 0.5 / 0.3 / 0.1）。
  - 绘制气压线时使用的 `pressureColor.copy(alpha = 0.7f)` 改为 `0.35f`。

### 2.2 背景竖线

- 当前竖线数量与时间标签数一致：`timeLabelCount = minOf(records.size, 6)`，竖线循环 `for (i in 0 until timeLabelCount)`。
- 改为：竖线数量加倍，时间轴标签仍用 `timeLabelCount` 不变。引入 `verticalGridLineCount = (timeLabelCount - 1).coerceAtLeast(0) * 2 + 1`，即竖线数约为 2*timeLabelCount-1（如 6→11），或简化为 `verticalGridLineCount = maxOf(2, timeLabelCount * 2)`使竖线数明确加倍（6→12）。采用「竖线数 = 2 * timeLabelCount」且当 timeLabelCount<=1 时竖线 1 条，即`verticalGridLineCount = if (timeLabelCount <= 1) 1 else timeLabelCount _ 2`。竖线 x 坐标：`leftAxisX + (chartWidth / (verticalGridLineCount - 1).coerceAtLeast(1)) _ i`，`i in 0 until verticalGridLineCount`。
