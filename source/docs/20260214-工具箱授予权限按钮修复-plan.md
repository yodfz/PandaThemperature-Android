# 工具箱授予权限按钮修复 - 开发计划

## 一、需求背景

用户反馈：工具箱里的两个工具（营地助手、营地回溯）中，「授予权限」按钮显示为灰色且无法点击。

## 二、问题分析

### 2.1 涉及位置

- **CampAssistantScreen**（营地助手）：`WindDetectionStep` 中的麦克风权限按钮
- **TrailBackScreen**（营地回溯）：`AnchorPhase` 中的位置+相机权限按钮

### 2.2 可能原因

1. **Material3 Button 默认状态**：未显式设置 `enabled = true` 时，可能受 CompositionLocal 等影响
2. **触摸区域**：按钮未满足 Material 最小 48dp 交互尺寸
3. **modifier 传递**：CampAssistantScreen / TrailBackScreen 未接收 ToolsScreen 的 modifier，可能影响布局与点击区域
4. **视觉反馈**：主题或样式导致按钮看起来像禁用状态

## 三、实现方案

### 3.1 修改清单

| 文件                   | 修改内容                                                                             |
| ---------------------- | ------------------------------------------------------------------------------------ |
| CampAssistantScreen.kt | 授予权限 Button 增加 `enabled = true`、`Modifier.heightIn(min = 48.dp)`、明确 colors |
| TrailBackScreen.kt     | 同上                                                                                 |
| ToolsScreen.kt         | 将 modifier 传递给 CampAssistantScreen、TrailBackScreen                              |

### 3.2 具体改动

1. **授予权限 Button 修改**

   - 显式设置 `enabled = true`
   - 添加 `Modifier.heightIn(min = 48.dp)` 确保最小触摸区域
   - 使用 `ButtonDefaults.buttonColors()` 显式指定 enabled 状态颜色，避免灰显

2. **ToolsScreen modifier 传递**
   - `CampAssistantScreen(onBack = ..., modifier = modifier)`
   - `TrailBackScreen(onBack = ..., modifier = modifier)`
