# 首页未连接状态显示功能开发计划

> 开发日期：2026-01-26

## 一、需求背景

当设备未连接时，首页需要显示友好的占位符界面，引导用户进行设备连接。根据设计图，需要实现以下功能：

1. **顶部状态栏**：显示"未连接设备"和"待连接..."，右上角显示电池占位符
2. **实时数据卡片**：显示占位符数据，中央有蓝色"点击连接"按钮
3. **趋势分析卡片**：显示空状态（植物图标 + 提示文字）
4. **历史预览卡片**：显示占位符历史记录

## 二、实现方案

### 2.1 StatusBar 组件修改
- 未连接时显示断开连接图标（带斜杠的蓝牙图标）
- 显示"未连接设备"和"待连接..."文字
- 右上角显示电池占位符（"-- %" 和 "-- V"）

### 2.2 RealtimeDataCard 组件修改
- 未连接时温度/湿度显示占位符 "-- °C" 和 "-- %"
- 最高/最低显示 "--:--"
- 在卡片中央添加蓝色连接按钮（带蓝牙图标和"点击连接"文字）
- 按钮使用绝对定位覆盖在卡片中央

### 2.3 TrendChartCard 组件修改
- 无数据时显示植物图标和"暂无实时趋势数据"文字
- 保留时间轴占位符

### 2.4 HistoryCard 组件修改
- 无数据时显示占位符历史记录项
- 日期："--年--月--日"，时间："--:--:--"
- 温度："--°C"，湿度："--%"

## 四、技术要点

- 使用 `connectionState` 判断是否连接
- 连接按钮使用 `Box` 绝对定位覆盖在卡片中央
- 占位符统一使用 "--" 格式
- 保持现有组件结构，仅调整显示逻辑
- 图标使用 Material Icons 或自定义绘制

## 五、注意事项

- 确保连接按钮的点击事件正确传递
- 占位符样式要与实际数据样式保持一致
- 空状态图标要选择合适的植物图标或使用 Material Icons
- 保持深色主题的一致性
