# 历史数据清空按钮优化开发计划

## 需求背景
用户希望优化历史数据清空功能的交互方式：
- 首页的历史数据卡片中，去掉"清空列表"按钮
- 在历史数据TAB页中，增加右上角菜单按钮
- 菜单中包含"清空列表"选项

## 实现方案

### 1. 首页历史卡片优化
- 移除 `HistoryCard` 组件中的"清空列表"按钮（OutlinedButton）
- 保留"获取历史数据"按钮，改为占满整行宽度
- 移除 `onClearHistory` 参数（或保留但不使用）

### 2. 历史数据TAB页菜单功能
- 在 `HistoryScreen` 中添加 `TopAppBar`
- 右上角添加菜单按钮（使用 `Icons.Default.MoreVert`）
- 实现 `DropdownMenu`，包含"清空列表"选项
- 点击清空列表后，调用 `viewModel.clearHistory()` 并刷新列表

### 3. 布局调整
- `HistoryScreen` 使用 `Scaffold` 包裹，顶部放置 `TopAppBar`
- 保持现有的下拉刷新功能（SwipeRefresh）
- 确保菜单按钮样式符合 Material Design 规范

## 开发计划列表

- [ ] 测试功能：验证清空列表功能正常工作
