# 设备固件版本号持久化

## 需求背景

当前设备固件版本号只在连接时从设备实时读取，没有持久化保存到设备表中。需要将固件版本号保存到 Device 实体，并在 UI 中显示。

## 实现方案

### 1. 数据层修改

- 给 `Device` 实体添加 `firmwareVersion` 字段
- 数据库版本升级（version 3 → 4）
- 添加数据库迁移脚本

### 2. 业务逻辑修改

- 连接成功后，读取到设备状态时更新设备的固件版本号
- 在 `MainViewModel` 中添加更新设备固件版本的方法

### 3. UI 显示

- 首页状态栏：优先使用实时读取的版本号，其次使用保存的版本号
- 设备列表：显示保存的固件版本号
