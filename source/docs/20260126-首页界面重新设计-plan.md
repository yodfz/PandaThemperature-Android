## 一、需求背景

根据提供的界面设计图，需要重新设计首页界面，使其更加现代化和直观。新设计包括：

1. **顶部状态栏**：蓝牙图标 + 设备名称 + 状态文本（左上角），电池信息（右上角）
2. **实时温湿度显示区**：左右分栏，显示图标、标题、大号数值、最高/最低值及时间
3. **趋势分析区（24h）**：24小时面积图
4. **历史预览区**：标题 + "全部 >"按钮，历史记录列表（日期、时间、温湿度）

## 四、技术细节

### 4.1 最高/最低值时间计算

由于设备只提供最高/最低值，不提供时间，需要从历史数据中计算：

```kotlin
// 伪代码
fun findMaxMinTime(
    records: List<TemperatureRecord>,
    maxValue: Float,
    minValue: Float
): Pair<String?, String?> {
    val maxRecord = records.find { it.temperature == maxValue }
    val minRecord = records.find { it.temperature == minValue }
    return Pair(
        maxRecord?.timestamp?.let { formatTime(it) },
        minRecord?.timestamp?.let { formatTime(it) }
    )
}
```
