# 设置页面设备管理功能开发计划

## 需求背景
用户希望在设置页面增加一个列表菜单，菜单中包含"设备管理"选项，点击后进入新页面显示所有已保存的设备，并支持侧滑删除功能。

## 实现方案

### 架构设计
```
SettingsScreen
  └── 内部状态管理子页面导航
        ├── 设置列表（默认）
        │     └── 设备管理菜单项
        └── DeviceManagementScreen（子页面）
              └── 侧滑删除设备列表
```

### 技术要点
1. **SettingsScreen 内部导航**：使用状态变量控制显示设置列表或设备管理页面
2. **侧滑删除**：使用 Compose Material3 的 `SwipeToDismissBox` 组件
3. **数据复用**：复用现有的 `savedDevices` Flow 和 `deleteDevice` 方法
