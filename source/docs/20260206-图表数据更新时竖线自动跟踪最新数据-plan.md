# 图表数据更新时竖线自动跟踪最新数据 - 开发计划

## 1. 需求背景

绘制图表时，若用户**没有**在触摸拖拽，则每次填充/更新数据时，应自动将拖拽竖线（crosshair）定位到**最新一条数据**。这样在实时或增量加载场景下，图表能始终展示最新数据的详情，而用户主动拖拽时不会被自动跳转打断。

## 2. 实现方案

### 2.1 逻辑说明

- **触摸拖拽时**：仅响应用户手势，不自动移动竖线。
- **未拖拽且数据更新时**：将 `selectedIndex` 设为 `records.size - 1`，`selectedTimeSec` 设为 `records.last().timestamp`，竖线自动移到最新数据点。

### 2.2 技术实现

1. **增加「用户正在拖拽」状态**

   - 使用 `var isUserDragging by remember { mutableStateOf(false) }`。
   - 在 `detectDragGestures` 中：
     - `onDragStart`: 设置 `isUserDragging = true`
     - `onDragEnd`: 设置 `isUserDragging = false`

2. **数据更新时自动定位到最新点**

   - 使用 `LaunchedEffect(records.size, records.lastOrNull()?.timestamp)`。
   - 当 `!isUserDragging` 且 `records.isNotEmpty()` 时：
     - `selectedIndex = records.size - 1`
     - `selectedTimeSec = records.lastOrNull()?.timestamp`

3. **边界情况**
   - `records` 为空时已有 early return，无需处理。
   - 首次加载时 `isUserDragging` 为 false，竖线会正确落在最新数据上。
