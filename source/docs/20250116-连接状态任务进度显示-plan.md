# 连接状态任务进度显示 - 开发计划

## 需求背景

用户希望在温度计连接之后，能够在连接状态的右侧显示当前正在执行的任务进度，例如：
- 正在连接中。。。
- 正在同步温湿度(1/4)
- 正在同步历史数据(2/4)
- 正在同步配置(3/4)

这样用户可以清楚地看到当前系统正在进行的具体任务。

## 实现方案

### 1. 数据结构设计

在 `MainViewModel` 中添加一个数据类来表示任务状态：
- 任务名称（当前任务描述）
- 任务序号（当前任务编号，从1开始）
- 总任务数（总共有多少个任务）

示例：
```kotlin
data class TaskStatus(
    val taskName: String?,  // null表示无任务
    val currentStep: Int = 0,
    val totalSteps: Int = 0
)
```

### 2. ViewModel 改动

**文件**: `app/src/main/java/com/example/pandatemperature/ui/viewmodel/MainViewModel.kt`

- 添加任务状态 StateFlow：
  ```kotlin
  private val _taskStatus = MutableStateFlow<TaskStatus?>(null)
  val taskStatus: StateFlow<TaskStatus?> = _taskStatus.asStateFlow()
  ```

- 在 `initializeDevice()` 方法中，为每个步骤更新任务状态：
  - 步骤1：同步时间 → "正在同步时间(1/6)"
  - 步骤2：读取采集间隔 → "正在同步配置(2/6)"
  - 步骤3：读取设备状态 → "正在读取设备状态(3/6)"
  - 步骤4：读取温湿度 → "正在同步温湿度(4/6)"
  - 步骤5：订阅实时数据 → "正在订阅实时数据(5/6)"
  - 步骤6：同步历史数据 → "正在同步历史数据(6/6)"
  - 完成后：清除任务状态（设为null）

- 在 `connectDevice()` 方法中，连接开始时设置任务状态为 "正在连接中..."

- 在 `resetConnectionState()` 方法中，清除任务状态

### 3. StatusBar 组件改动

**文件**: `app/src/main/java/com/example/pandatemperature/ui/components/StatusBar.kt`

- 添加 `taskStatus` 参数
- 在右侧（使用 `Arrangement.SpaceBetween` 的右侧）显示任务状态文本
- 修复第31行的bug（`isConnected` 变量未定义）
- 任务状态文本样式：
  - 使用 `MaterialTheme.typography.bodySmall`
  - 颜色使用 `MaterialTheme.colorScheme.onSurfaceVariant`
  - 如果是连接中的状态，可以添加动画效果（可选）

### 4. MainScreen 改动

**文件**: `app/src/main/java/com/example/pandatemperature/ui/screen/MainScreen.kt`

- 在 `HomeScreen` 中收集 `taskStatus` 状态
- 将 `taskStatus` 传递给 `StatusBar` 组件

### 5. 任务步骤定义

根据 `initializeDevice()` 方法的实际步骤，定义以下任务：
1. 同步时间
2. 同步配置（读取采集间隔）
3. 读取设备状态
4. 同步温湿度（读取温度和湿度）
5. 订阅实时数据
6. 同步历史数据

## 注意事项

1. 任务状态应该在连接断开时自动清除
2. 任务状态文本要简洁明了，不超过一行显示
3. 确保任务状态更新的时机准确，与实际执行步骤对应
4. 如果任务执行失败，也应该更新状态或清除状态
5. 保持UI简洁，不要影响现有的布局和视觉效果
