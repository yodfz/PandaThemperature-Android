# 历史数据时间筛选功能开发计划

## 需求背景

用户希望在历史数据页面的 Switch（列表/图表切换）下方增加日期+时间筛选功能：
- 支持起始时间和结束时间选择
- 历史数据列表和图表共用同一个时间筛选器
- 选择时间后显示重置小按钮
- 展开型 UI 样式

## 实现方案

### UI 设计

在 Switch 下方添加展开型时间筛选器：
```
[列表] [图表]                         ← 现有 Switch

┌─────────────────────────────────────────────┐
│ 起始时间: [2025-01-30] [08:00]              │
│ 结束时间: [2025-01-30] [18:00]    [重置]    │
└─────────────────────────────────────────────┘
```

- 点击日期显示 DatePickerDialog
- 点击时间显示 TimePickerDialog
- 重置按钮仅在选择了时间后显示
- 重置后清空筛选，显示全部数据

### 变动文件

1. **`TemperatureRecordDao.kt`** - 添加带时间筛选的分页查询方法
2. **`MainViewModel.kt`** - 添加时间筛选状态和查询逻辑
3. **`HistoryScreen.kt`** - 添加时间筛选器 UI 组件

## 技术要点

1. 使用 Android Material3 的 DatePicker 和 TimePicker
2. 时间戳使用秒级（与现有数据格式一致）
3. 筛选逻辑：起始时间 <= timestamp <= 结束时间
4. 默认不设置筛选（显示全部数据）
